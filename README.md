# real2sim-research

Miles 的 Real-to-Sim / real2sim2real **持久真源仓库**。

本库记录一切可复用研究资产：记忆、命题、证据卡、过程日志、方法论与运维约定。交互式看板与知识网络仍在 Cursor Pages；**GitHub 是可版本化、可 diff、可回滚的落库真源**。两者以 `ops/sync-protocol.md` 同步，禁止双真源漂移。

## 目录

| 路径 | 内容 |
|------|------|
| `docs/` | 治理、架构、读写约定 |
| `propositions/` | 四命题代号卡（可拆积木 / 多源成景 / 不冻栈 / 判官台） |
| `knowledge/` | 第一性原理、诊断、决策树、开放问题、证据卡 |
| `knowledge/cards/` | 单条工作/证据卡（一卡一文件） |
| `methodology/` | 知识型大脑 / RSI 方法论 |
| `ops/` | 花名册、例行、X list、同步协议 |
| `journal/` | 按日过程日志（并网、审计、决策） |
| `memory/` | Standing 原则与代号（从 agent profile 镜像） |
| `sources/` | 外部 URL 索引（非镜像全文） |

## 命题代号

- **可拆积木** — 生成层：对象级可编辑、可组合进仿真的 GS 资产
- **多源成景** — 使用层：多模态输入 → 约束摆放 → sim-ready 场景
- **不冻栈** — RSI：领域变强时 agent 判断栈禁止冻结
- **判官台** — 总控：可辩护的 real2sim2real 专家判断

## 证据等级

- **A**：代码 + 评测协议 + 真机对照，失败模式同族可查
- **B**：理论/叙事清楚，落地部分公开
- **C**：演示/二手/无基准 → 默认丢弃，不入库卡
