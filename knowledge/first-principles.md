# 第一性原理

Real2Sim2Real 成功 = 三件事同时成立：

1. **可观测（Observability）**：要控制的量在真实传感器里能否估计？不可估 → 先感知/标定。
2. **可演化（Dynamical sufficiency）**：仿真是否产生与真机同族失败模式？外观对、失败模式不对 = 错误监督。
3. **可预测迁移（Rank-preserving transfer）**：仿真变好时真机相对表现是否同向？不同向 → 仿真评测不能当决策依据。

附加：最小充分表示；因果归属；闭环完整性（闭合真机对照才可升 A）；**阶段性成果**（近达标 = stage-win，同族打磨，禁止二元驳回换栈）。
