# 证据与采信

等级：`A` | `A-` | `B+` | `B` | `C`。另设轨道 **规范/工具**（无真机对照仍可高信任，但不得写进「真机 A」叙事）。

- **A**（方法/系统）：公开代码 + 明确评测协议 + 真机对照 + 同族失败可查 → 可指导选型
- **A-**：三要件缺一，但有可复核公开产物（代码或项目页）+ 清楚机制/数字出处 → 可作强候选，需补对照
- **B+**：方向清楚且有部分可复核产物，缺协议或真机 → 可试点，不单独定栈
- **B**：理论或一手叙事清楚，落地部分公开 → 可作方向，需复现
- **C**：演示、二手转发、无基准 → 默认降权，不建卡
- **规范/工具**：字段规范、验收工具、基准脚手架；要求公开仓库/规范正文可点；**不要求真机**；Pages 图例须单独成句

`hard_metrics` 必须可复核（URL / 协议名 / 对照设定），禁止仅写「代码+项目」。
