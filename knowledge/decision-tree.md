# 瓶颈决策树

| 若卡点是… | 第一性原理含义 | 优先动作 | 常见错误 |
|-----------|----------------|----------|----------|
| 策略在真机乱碰物体 | 可演化不足 | 轨迹对照标定质量/摩擦；接触日志 | 只提高渲染分辨率 |
| 视觉像、策略仍漂 | 可观测或域差 | 核对状态估计；twin 同步 | 无脑 domain randomization |
| 仿真高分真机低分且排序翻 | 可预测迁移破裂 | 停用该仿真指标选型 | 继续用仿真排行榜 |
| 资产建不出/太贵 | 最小充分表示失控 | 按任务裁剪；3DGS+物理或扫描管线 | 追求电影级全场景 |
| 对象边界糊/不可拆 | 可组合表示不足 | 对象 densify；边界带损失；RQS | 均分 GS；只追全局 PSNR |
| 能拼景但不可仿真 | 元数据/约束/门禁缺 | 资产卡 + 约束摆放 + checklist | 观感当 ready |
| 演示少要鲁棒 | 需孪生探索 | RialTo 类 | 只堆 teleop |
| 从视频教人形 | 人-场景联合重建 | VideoMimic 类 | 直接塞人体姿态 |
