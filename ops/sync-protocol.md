1. EditCanvas / 记忆写入（交互面）

4. FYI 专职（priority false 除非待办）
5. Commit message 格式：`merge: <slug>(<grade>) · <prop> · YYYY-MM-DD`

禁止：只改 Page 不落库；只落库不改 Page；C 级建卡。
