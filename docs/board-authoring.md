> 真源口径仍以 `knowledge/*` · `propositions/*` 为准。

## 屏权（实现门禁用语 · 仅 docs）

| 旧 UI 串 | 含义 | 读者页替代 |
|---|---|---|

## 证据政策（禁止句 · 仅 docs）

- **禁止伪造**实验输出当真实效果；禁止把论文截图/Agent 生成图当作本机效果。
- **禁止**：伪造 % 或未跑实验成功线。
- 案例位：**禁止**大空「【真实案例位 · 空】」说明书占位；改概念示意或待验证事项列表。
- 视觉例证三类互斥：`外部公开` / `概念示意` / `本机实验`；本机无结果禁 `local`；外部图必注「非本机」。
- **禁止笼统「已验证」**；拆四标签：外部证据 | 作者/第三方复现 | 本机实验 | 工程集成。
- 页脚：**禁止**「不合 main 直至编排核链」类流程句进读者 UI。

## 四标签 ↔ cards `evidence_tags`

| UI 短名 | 卡面完整名 |
|---|---|
| 外部证据 | 外部报道/论文结论 |
| 作者/第三方复现 | 开源复现 |
| 本机实验 | 本机对照 |
| 工程集成 | 场景适配工程判断 |

无 tag → UI「无记录」，禁静默变绿。真机矩阵列 ≠ 本机标签。
