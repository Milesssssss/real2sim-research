# 治理约定

## 双面真源（禁止漂移）

| 面 | 角色 | 权威范围 |
|----|------|----------|
| Cursor Pages | 交互判断面（看板、可视化、日更） | 当前状态的可读视图 |
| 本 GitHub 库 | 持久落库（版本、diff、回滚、全量细节） | 证据卡、过程、记忆镜像、协议 |

规则：
1. **硬结论、证据卡、开放问题、默认栈** 变更必须同日写入本库对应文件。
2. Page 改写后，同日在 `journal/YYYY-MM-DD-*.md` 记一条「并网/改写」摘要，并更新 `knowledge/` 或 `propositions/`。
3. 不另起第二套知识网络；本库是 Page 的 git 镜像 + 更细粒度过程。
4. C 级线索可进 `journal/` 脚注，**不**建 `knowledge/cards/`。

## 写入权

- 刘亦菲：结构、并网、默认栈、开放问题、记忆镜像
- 沈括回传经核链后：由刘亦菲落卡；矿工不直写本库
- 达摩提案：进 `journal/` + `methodology/` 草案；晋升需门禁

## 命名

- 证据卡文件：`knowledge/cards/<Slug>.md`（与论文常用名一致）
- 日志：`journal/YYYY-MM-DD-<topic>.md`
- 命题：固定四文件，不另起别名目录
